1. Excel Fundamentals for Data Analysts

Workbook, Worksheet, Rows, Columns, Cells

  • Workbook – The entire Excel file (.xlsx).
  • Worksheet – A single sheet within a workbook.
  • Rows – Horizontal (numbered 1, 2, 3…).
  • Columns – Vertical (lettered A, B, C…).
  • Cell – Intersection of row & column (e.g., A1).
Data Analysts work with tabular data – rows are records, columns are fields.

Relative, Absolute & Mixed References

TypeExampleBehaviour when copied
RelativeA1Both row & column change
Absolute$A$1Neither changes
Mixed (row locked)A$1Column changes, row fixed
Mixed (column locked)$A1Row changes, column fixed
Forgetting to lock a reference when dragging a formula → wrong results. Always ask: "Should this cell stay the same?"
Interviewers often test relative vs absolute by giving a SUMIF formula and asking what happens when dragged.

Named Ranges

Give a cell or range a meaningful name (e.g., SalesData). Use in formulas for readability.

=SUM(SalesData)
Named ranges make formulas easier to audit – mention this in interviews.

Excel Tables & Structured References

Convert a range to a Table (Ctrl+T). Benefits: automatic expansion, structured references, calculated columns.

=SUM(Sales[Revenue])
Tables auto-fill formulas and keep references intact when new rows are added.

Sorting, Filtering, Custom Sorting

  • Sort – Arrange data ascending/descending.
  • Filter – Show only rows that meet criteria.
  • Custom Sort – Sort by multiple levels or custom lists.
Use sorting to find top customers; filtering to isolate a region.

Freeze Panes, Find & Replace, Remove Duplicates

  • Freeze Panes – Keep headers visible while scrolling.
  • Find & Replace – Clean inconsistent text (e.g., "NY" → "New York").
  • Remove Duplicates – Data → Remove Duplicates. Always check before removing!
Removing duplicates without checking if they are genuine duplicates or legitimate repeated orders.

Data Validation & Conditional Formatting

  • Data Validation – Restrict input (e.g., dropdown lists, whole numbers).
  • Conditional Formatting – Highlight cells based on rules.
⭐ MUST KNOW: Conditional formatting is heavily used in dashboards. Know how to highlight duplicates, top 10%, and negative values.

2. Important Excel Formulas

Basic Aggregation

FunctionWhat it doesExample
SUMAdds numbers=SUM(A1:A10)
AVERAGEArithmetic mean=AVERAGE(B1:B10)
MIN / MAXSmallest / largest=MIN(C1:C10)
COUNTCounts numeric cells=COUNT(D1:D10)
COUNTACounts non-empty cells=COUNTA(E1:E10)
COUNTBLANKCounts empty cells=COUNTBLANK(F1:F10)
Using COUNT instead of COUNTA for text columns – COUNT only counts numbers.

Conditional Aggregation

FunctionPurposeExample
SUMIFSum with one condition=SUMIF(Region,"West",Sales)
SUMIFSSum with multiple conditions=SUMIFS(Sales,Region,"West",Category,"Tech")
COUNTIFCount with one condition=COUNTIF(Region,"West")
COUNTIFSCount with multiple conditions=COUNTIFS(Region,"West",Sales,">1000")
AVERAGEIFAverage with one condition=AVERAGEIF(Category,"Tech",Sales)
AVERAGEIFSAverage with multiple conditions=AVERAGEIFS(Sales,Region,"West",Category,"Tech")
⭐ MUST KNOW: Difference between SUMIF vs SUMIFS – SUMIFS is more flexible and the order of arguments is different (sum_range first).
SUMIFS syntax: =SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], …)
In SUMIF, the sum_range is last; in SUMIFS, it's first. Mixing them up gives wrong results.

IF vs IFS

  • IF – One condition, two outcomes.
  • IFS – Multiple conditions, no nesting required.
=IF(A1>100,"High","Low")
=IFS(A1>100,"High", A1>50,"Medium", TRUE,"Low")
IFS is cleaner but only available in Excel 2019+. Mention compatibility.

3. Logical Functions

FunctionUseExample
IFBasic conditional=IF(Sales>1000,"Good","Bad")
IFSMultiple conditions=IFS(Sales>1000,"A",Sales>500,"B",TRUE,"C")
ANDAll conditions true=AND(A1>0,B1>0)
ORAny condition true=OR(A1>0,B1>0)
NOTReverses logic=NOT(A1>0)
IFERRORHandle any error=IFERROR(VLOOKUP(...),"Not Found")
IFNAHandle #N/A only=IFNA(VLOOKUP(...),"Missing")

Nested IF – When to use / avoid

Nested IFs become hard to read. Use IFS or a lookup table instead when possible.

Deeply nested IFs (5+ levels) → high error rate. Switch to IFS or XLOOKUP with approximate match.

Customer Segmentation Example

=IF(Sales>=10000,"Platinum", IF(Sales>=5000,"Gold", IF(Sales>=1000,"Silver","Bronze")))
Segmentation helps marketing target customers effectively.

4. Lookup Functions – ⭐ VERY IMPORTANT

VLOOKUP

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • Exact match: FALSE or 0
  • Approximate: TRUE or 1 (requires sorted data)
Forgetting the last argument → defaults to approximate match → wrong results.

HLOOKUP

Same as VLOOKUP but searches horizontally across rows.

XLOOKUP

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
⭐ MUST KNOW: XLOOKUP is preferred over VLOOKUP because it can look left, has built-in if_not_found, and defaults to exact match.

INDEX + MATCH

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

More flexible than VLOOKUP – can look left and right.

MATCH & XMATCH

=MATCH(lookup_value, lookup_array, [match_type])
=XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])

Comparison Table

FeatureVLOOKUPXLOOKUPINDEX-MATCH
Look left❌✅✅
Default exact match❌✅✅
Built-in if_not_found❌✅❌
Insert column safe❌✅✅

Realistic Example

Table 1: Customer_ID | Customer_Name | Region | Sales

Table 2: Customer_ID | Order_Date | Amount

=XLOOKUP(A2, Customers[Customer_ID], Customers[Customer_Name], "Not Found")
Common question: "What happens if lookup value is not found?" → VLOOKUP returns #N/A; XLOOKUP can return a custom value.

7. Data Cleaning in Excel – ⭐ VERY IMPORTANT

Common Data Issues & Fixes

IssueFix
Missing valuesFilter blanks, impute or remove
Duplicate recordsRemove Duplicates or COUNTIF check
Extra spaces=TRIM()
Inconsistent case=PROPER(), =UPPER(), =LOWER()
Numbers stored as text=VALUE(), Text to Columns, Multiply by 1
Invalid datesText to Columns, DATEVALUE
Errors (#N/A, #VALUE!)IFERROR, IFNA

Step-by-Step Cleaning Process

  1. Understand the dataset (columns, meaning, source).
  2. Check data types (numbers, dates, text).
  3. Handle missing values (decide: remove, impute, flag).
  4. Remove duplicates (verify first).
  5. Standardize text (TRIM, PROPER, SUBSTITUTE).
  6. Validate dates (convert text to date).
  7. Check numerical anomalies (outliers, negatives).
  8. Validate business rules (e.g., sales >= 0).
  9. Document transformations.
  10. Recheck final dataset (row counts, summaries).
⭐ MUST KNOW: "How would you clean a messy Excel dataset?" – Use the 10-step framework above.

9. Pivot Tables – ⭐ VERY IMPORTANT

What is a Pivot Table? A tool to summarize, analyze, and present large datasets interactively.

  • Rows – Categories to group by.
  • Columns – Cross-tabulation.
  • Values – Aggregations (Sum, Count, Average).
  • Filters – Filter entire pivot.
  • Slicers – Visual filters.
  • Grouping – Group dates, numbers.
  • Show Values As – % of total, running total, difference from.
Use Pivot Tables for: Sales by Region, Sales by Category, Monthly Revenue, Top Customers, Orders by Segment.
⭐ MUST KNOW: How to create a Pivot Table, add calculated fields, and use Show Values As.

10. Pivot Charts & Slicers

  • Pivot Chart – Visualize Pivot Table data.
  • Slicer – Buttons to filter Pivot Tables/Charts.
  • Timeline – Date filter for Pivot Tables.
Create an interactive sales dashboard: Pivot Table → Pivot Chart → Slicers for Region, Category, Year.
Slicers can be connected to multiple Pivot Tables – great for dashboards.

Applying CF to the wrong range or using relative references incorrectly.

12. Power Query – Entry-Level Relevance

What is Power Query? ETL tool inside Excel for importing, transforming, and loading data.

  • Import data from multiple sources.
  • Remove/rename columns, change data types.
  • Remove duplicates, handle missing values.
  • Split/merge columns, replace values, filter rows.
  • Append – Stack tables vertically (add rows).
  • Merge – Join tables horizontally (like VLOOKUP).
  • Group By, Unpivot, Pivot.
⭐ MUST KNOW: Merge vs Append – Merge combines columns from different tables; Append adds rows from similar tables.
Power Query is ideal for repeatable data cleaning – just refresh when new data arrives.

15. Data Analysis Concepts Using Excel

For each business question: Business Question → Data Needed → Excel Approach → Formula/Pivot → Interpretation

Example 1: Which region generates the highest revenue?

  • Data: Region, Revenue
  • Approach: SUMIF or Pivot Table
  • Formula: =SUMIF(Region,"West",Revenue)
  • Interpretation: West contributes 40% of total revenue.

Example 2: Top 10 customers

  • Approach: Sort by Sales descending, take top 10.
  • Formula: =LARGE(Sales, 10) or Pivot Table Top 10 filter.

Example 3: Month-over-Month Growth

  • Formula: =(ThisMonth - LastMonth)/LastMonth
  • Use Pivot Table with Show Values As → % Difference From.
Always validate results with a second method (e.g., check SUM against Pivot Table total).

17. Realistic Data Analyst Case Studies

Case Study 1 — E-commerce Sales

Dataset: Order_ID, Customer_ID, Order_Date, Region, Category, Product, Quantity, Sales, Discount, Profit

Business Questions:

  • Which region has the highest sales?
  • Which category is most profitable?
  • What is the monthly revenue trend?

Excel Approach: Pivot Table (Region → Sum of Sales), Pivot Chart (Monthly trend), Conditional Formatting for profit.

Case Study 2 — Customer Analysis

Analyze new vs repeat customers, revenue by customer, top customers, contribution %.

Formula: =COUNTIF(Customer_ID, A2)>1 → Repeat flag.

Case Study 3 — Retail Performance

Analyze Region, Category, Product, Sales, Profit, Discount.

Insight: High sales but low profit → high discounts. Use scatter plot or conditional formatting.

Case Study 4 — HR Analytics

Analyze Department, Salary, Experience, Attrition, Performance.

Formula: =AVERAGEIF(Department,"Sales",Salary)

Case Study 5 — Operations

Analyze Order Date, Delivery Date, Shipping Mode, Delivery Time, Region.

Formula: Delivery Time = =DeliveryDate - OrderDate. Use NETWORKDAYS for working days.

Always explain the business reasoning, not just the formula.

20. Excel Mistakes That Can Hurt a Data Analyst Interview

  • Using approximate match accidentally in VLOOKUP.
  • Forgetting absolute references ($) when dragging formulas.
  • Using wrong aggregation (SUM vs COUNT).
  • Ignoring duplicates.
  • Ignoring missing values.
  • Incorrect date handling (text vs date).
  • Hardcoding values instead of using cell references.
  • Not validating results.
  • Using formulas without understanding the business question.
  • Creating misleading charts (e.g., truncated y-axis).
  • Not checking data types.
  • Using too many nested IFs instead of IFS or lookup.
  • Not documenting assumptions.
Any of these can cost you the interview – double-check your work.
